## Что сделано

### Среда и цикл с точкой проверки

- `checks/check_hw1_fasta.py` — независимая проверка статистики FASTA на
  стандартной библиотеке Python 3. Сверяет SHA-256 `source` и
  `original_source` из `homework/inputs.tsv`, сам разбирает каждый FASTA
  (length_bp, a/c/g/t/ambiguous, gc_percent), читает
  `results/hw1/fasta_stats.csv` с требуемым порядком столбцов и ровно тремя
  строками, сверяет целые точно и gc_percent с допуском 1e-6.
- `scripts/hw1_fasta_stats.py` — расчёт статистики трёх FASTA; результат —
  `results/hw1/fasta_stats.csv` (KU361241.1 151324 bp / GC 37.68602469,
  KU736960.1 151307 bp / GC 37.69025888, NC_032056.1 151282 bp /
  GC 37.67863989; ambiguous_count 0).
- Цикл «расчёт → проверка»: `python3 scripts/hw1_fasta_stats.py` затем
  `python3 checks/check_hw1_fasta.py` — фактический код 0, «OK: все проверки
  пройдены».
- Точка проверки: на испорченной копии таблицы (GC KU361241.1 +1)
  `python3 checks/check_hw1_fasta.py --result /tmp/bad.csv` вернул код 1;
  на правильной таблице — код 0. Зафиксировано в `diary.md` (2026-10-14).
- Независимая проверка FASTA выполнена отдельной сессией до расчёта
  (журнал `reports/agent_runs/fasta_check_session.log`); расчёт —
  `fasta_calc_session.log`; исправление формулы GC — `fasta_fix_session.log`.
