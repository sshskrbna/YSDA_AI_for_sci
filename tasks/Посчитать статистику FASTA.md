# Посчитать статистику FASTA

Запрос пользователя: посчитать статистику трёх учебных FASTA (KU361241.1, KU736960.1, NC_032056.1) и записать результат в `results/hw1/fasta_stats.csv`.

Готово, когда: `python3 checks/check_hw1_fasta.py` возвращает код 0.

Не входит: не пересчитывать деревья; не изменять исходные FASTA.

## Итог

Написан `[[scripts/hw1_fasta_stats.py]]` (только стандартная библиотека): читает `homework/inputs.tsv`, разбирает каждый FASTA из `source`, считает length_bp, a/c/g/t_count, ambiguous_count и gc_percent = (g+c)/(a+c+g+t)*100 с 8 знаками. Результат — `[[results/hw1/fasta_stats.csv]]` с тремя строками: KU361241.1 (151324 bp, GC 37.68602469), KU736960.1 (151307 bp, GC 37.69025888), NC_032056.1 (151282 bp, GC 37.67863989), ambiguous_count 0. Проверка `[[checks/check_hw1_fasta.py]]` независимо пересчитывает результат; фактический код 0, «OK: все проверки пройдены».
